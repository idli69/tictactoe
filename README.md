# Tic Tac Toe!

A tiny little Tic Tac Toe game made with **Svelte 5** and **Tailwind CSS**!

## How to play?

- Duh!
- Get 3 in a row to win!
- Hit the Reset button to play again!

## Made with

- Svelte 5
- Tailwind CSS

## Run it locally

1. Clone this repo.
2. Install the dependencies with `npm install`.
3. Start the game with `npm run dev`.
4. Open the link in your browser!

Have fun playing! :D
